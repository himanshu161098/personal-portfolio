# Stack Guide

Suggested reference stack (agent may substitute equivalent technologies with documented reason):

Frontend: React + TypeScript + Vite/Next.js
Backend: FastAPI or Node/Nest-style typed API
Database: PostgreSQL
Vector: pgvector
Object storage: S3-compatible
Queue: Redis-backed job queue
Testing: unit + integration + e2e
CI: GitHub Actions
Containers: Docker

Choose the simplest stack that satisfies the PRD and document substitutions in an ADR.
