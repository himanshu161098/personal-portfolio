# Threat Model

Consider:
- account takeover;
- cross-tenant data access;
- malicious file uploads;
- prompt injection;
- tool abuse;
- SSRF;
- secret leakage;
- data exfiltration;
- model misuse;
- denial of service;
- insecure direct object references;
- dependency vulnerabilities.

For each threat document:
attack surface -> impact -> likelihood -> control -> test -> residual risk.
