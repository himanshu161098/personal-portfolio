# Agent Output Contract

For each completed phase, report:

## Phase summary
- phase name
- objective
- implementation completed

## Files
- important files created/changed

## Validation
- lint/format result
- unit tests
- integration tests
- build result
- manual checks

## Product impact
- user-visible changes

## Risks
- remaining risks

## Deferred
- work moved to later phase

## Documentation
- documents updated

Never report “done” if a required gate failed. State the failure precisely.
