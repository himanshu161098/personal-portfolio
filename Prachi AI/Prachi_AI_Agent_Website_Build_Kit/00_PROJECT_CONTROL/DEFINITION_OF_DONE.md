# Definition of Done

A feature is done only when:

- requirements are mapped to implementation;
- happy path works;
- invalid input is handled;
- authorization is enforced;
- sensitive data is protected;
- tests exist for critical logic;
- documentation is updated;
- telemetry/logging is adequate without secret leakage;
- UI is responsive and accessible enough for the supported scope;
- error and empty states are handled;
- acceptance criteria are satisfied;
- phase evidence is recorded;
- no known blocking regression remains.
