# Design System

## Brand
Prachi AI should feel modern, calm, intelligent, trustworthy, and personal.

## UX priorities
1. Clarity
2. Speed
3. Trust
4. Accessibility
5. Recoverability

## Core surfaces
- Landing
- Auth
- Chat
- Assistant dashboard
- Memory
- Tasks
- Files
- Projects/workspace
- Research
- ML insights
- Settings/privacy
- Admin

## Components
Button, input, textarea, select, modal, drawer, toast, card, tabs, table, chat bubble, tool activity card, artifact preview, citation chip, memory card, task card, file card, command palette.

## Responsive rules
- Mobile-first behavior.
- No critical action should depend on hover.
- Preserve readable text widths.
- Maintain keyboard accessibility.
