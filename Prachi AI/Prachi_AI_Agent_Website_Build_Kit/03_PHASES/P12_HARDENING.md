# P12 — Hardening + Performance

Goal: production-readiness pass.

Deliverables:
- rate limits;
- caching where safe;
- background jobs;
- retries/circuit breakers;
- DB/index review;
- file scanning;
- dependency audit;
- load/performance tests.

Gate:
- no known critical security findings;
- critical flows meet performance targets;
- failure recovery tested.
