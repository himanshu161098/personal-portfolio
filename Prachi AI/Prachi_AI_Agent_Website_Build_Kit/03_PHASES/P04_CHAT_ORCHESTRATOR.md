# P04 — AI Chat + Orchestrator

Goal: natural conversation and mode-based routing.

Deliverables:
- provider adapter;
- chat streaming where appropriate;
- mode selection;
- context composition;
- tool routing interface;
- structured errors.

Gate:
- chat works with configured provider;
- demo/local fallback exists where useful;
- provider can be swapped through adapters;
- unauthorized data is never injected into prompts.
