# P08 — ML + Forecasting

Goal: build a model service for predictions and recommendations.

Deliverables:
- dataset contract;
- feature pipeline;
- model versioning;
- evaluation metrics;
- prediction API;
- confidence/uncertainty representation;
- model monitoring hooks.

Gate:
- baseline metric established;
- prediction inputs validated;
- forecast is clearly described as an estimate;
- training and inference versions are traceable.
