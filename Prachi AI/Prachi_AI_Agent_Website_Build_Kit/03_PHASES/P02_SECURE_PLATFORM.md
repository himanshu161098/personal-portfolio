# P02 — Secure Platform Foundation

Goal: identity, sessions/tokens, authorization, persistence, file boundary, audit basics.

Deliverables:
- authentication;
- authorization middleware;
- user/tenant model;
- migrations;
- secure file metadata;
- audit event foundation;
- secrets configuration.

Gate:
- cross-user access tests fail safely;
- secrets are server-only;
- protected endpoints require auth;
- uploads are validated.
