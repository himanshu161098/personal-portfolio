# P06 — Vision + Image Workflows

Goal: image understanding and creation/editing.

Deliverables:
- multimodal input;
- OCR adapter;
- object detection adapter;
- image analysis UI;
- image generation/editing provider adapter;
- artifact versioning.

Gate:
- supported formats are validated;
- provider outputs are stored safely;
- edit history is preserved;
- failures produce usable messages.
