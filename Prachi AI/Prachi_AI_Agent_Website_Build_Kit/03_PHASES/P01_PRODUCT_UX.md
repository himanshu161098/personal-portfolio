# P01 — Product + UX Contract

Goal: convert PRD into concrete screens, flows, states, and design tokens.

Deliverables:
- information architecture;
- dashboard/chat/workspace flows;
- responsive layout;
- empty/loading/error states;
- accessibility baseline;
- component inventory.

Gate:
- primary user journeys are implementable without ambiguity;
- UI states are documented;
- design system tokens are established.
