# User Stories

US-001: As a user, I can register/login and access only my own workspace.
US-002: As a user, I can chat naturally with Prachi AI.
US-003: As a user, I can ask Prachi to remember something and manage that memory.
US-004: As a user, I can upload a document and ask questions about it.
US-005: As a user, I can upload an image and ask for analysis.
US-006: As a user, I can ask Prachi to create a document or image artifact.
US-007: As a user, I can ask Prachi to modify a generated artifact.
US-008: As a user, I can get data-based forecasts with uncertainty information.
US-009: As a user, I can create tasks/reminders.
US-010: As a user, I can use research mode with citations.
US-011: As a user, I can choose preferences/language/assistant behavior.
US-012: As an admin, I can inspect system health and audit information.
